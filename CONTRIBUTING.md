# Contributing

Sluice is a display project. It is built and maintained by one person, for
personal use, and shared publicly as a working example rather than as an
open, maintained tool.

That means, plainly:

- **Contributions are not being sought.** There is no roadmap issue list
  waiting for a pull request, and no intent to build a contributor community
  around this repository.
- **Issues and pull requests may go unanswered.** They are not ignored out of
  rudeness. There is no committed response time and no maintenance
  obligation.
- **A pull request that does land is still governed by [`CLA.md`](CLA.md).**
  Read it before opening one. It asks for more than the license already
  grants, specifically a right to relicense your contribution, and any patch
  merged without that signed is not merged.

Using, studying, forking, or building on Sluice is different. What you may
do there is already answered by the license in [`LICENSE`](LICENSE) and the
naming rule in [`TRADEMARK.md`](TRADEMARK.md). Doing any of it needs no
permission or response from the maintainer.
